# Rx/Tx performance baseline — 2026-08-16

## Environment

- Host: Apple Silicon ARM64 (`T8132`), macOS 26.6
- Build: Cargo optimized bench profile, Criterion 0.8
- Hardware SDR: not exercised; results below use deterministic mock/generator paths
- Sampling: 100 ms warm-up, 300 ms measurement, 10 samples. These short local runs establish the harness and rank obvious work; CI trends and optimization acceptance should use longer runs.

## Ceiling interpretation

At 3.2 MS/s, the uncapped sample-production ceilings are 1,562 FPS at 2,048 samples, 97 FPS at 32,768 samples, and 12 FPS at 262,144 samples. The configured 60 FPS screen target applies only to presentation and must not cap these theoretical or benchmark loops.

## First optimization receipt

The HackRF callback previously filled its native transfer buffer one byte at a time using a modulus operation. For a 256 KiB callback buffer:

| Implementation | Median time | Relative result |
| --- | ---: | ---: |
| Per-byte modulus baseline | 158.52 µs | 1.0x |
| Repeated bulk slice copies | 3.851 µs | **41.2x faster** |

The byte-for-byte repetition contract is regression-tested, including a partial final copy. Physical HackRF throughput and USB utilization remain unverified because no hardware run was performed.
