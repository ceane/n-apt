# Validation levels

Use the smallest truthful claim:

- A unit test proves a function for its fixture.
- A deterministic replay proves repeatable processing for that input.
- A rendered app check proves the displayed path.
- A live SDR check proves behavior with a connected receiver.
- Physical hardware evidence is required for hardware-specific continuity or TX/RX claims.

Always report passed, skipped, environment-blocked, and real failures separately. Do not call a signal “identified” from FFT energy alone.
